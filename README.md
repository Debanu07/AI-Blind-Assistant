# AI-Blind-Assistant

A computer vision system that detects objects in real time using YOLOv8 and provides voice feedback describing their position and distance.

## Features

- Real-time object detection
- Spatial awareness (left / ahead / right)
- Distance estimation (far / near / very close)
- Audio feedback using pyttsx3
- Threaded speech system to prevent video lag

## Technologies Used

- Python
- OpenCV
- YOLOv8
- pyttsx3

## Installation

Install dependencies:

pip install -r requirements.txt

## Run the project

python main.py
